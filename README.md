# Guigui — Roue des Subs Kick V4

## Nouveauté principale
Un bouton **⚙️ Gestion** est disponible en haut de l'écran.

- Clique dessus pour masquer toute la colonne de gestion.
- La roue prend alors toute la largeur disponible.
- Le bouton devient **⚙️ Afficher la gestion** pour la faire réapparaître.
- Le choix est mémorisé dans le navigateur : si tu fermes le site en mode live, il pourra rester en mode live à la prochaine ouverture.

## Fonctionnalités conservées
- Grand affichage du lot gagnant au centre
- Bouton OK / clic extérieur / Échap pour fermer le gagnant
- Effet sonore de victoire
- Export / import JSON
- Plusieurs roues
- Ajout / modification / suppression des lots
- Suppression de roue avec confirmation
- Les lots restent présents après les tirages
- Historique
- Sauvegarde locale
- Interface PC et mobile
- Design Guigui bleu/cyan/doré
