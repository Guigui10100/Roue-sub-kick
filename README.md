# Guigui — Roue des Subs Kick V2

- Plusieurs roues
- Ajout, modification et suppression des lots
- Quantité et couleur personnalisées
- Animation de tirage
- Historique par roue
- Suppression d'une roue avec confirmation
- **Les lots ne sont jamais supprimés ni diminués après un tirage**
- Sauvegarde automatique dans le navigateur
- Compatible PC et mobile
- Fonctionne comme site statique GitHub Pages

## GitHub Pages
Dépose `index.html` et `logo.jpg` à la racine du repository, puis active
Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Sauvegarde
Les données sont enregistrées dans le navigateur avec localStorage.
Elles restent donc disponibles sur le même navigateur et le même appareil.
